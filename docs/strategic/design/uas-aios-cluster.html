八条协议

北 · hub.*使用平面唯一入口。剖面由服务端强制。
南 · MCP / cs.*模型只见语义名。list 过滤不能跳过 call 判定。
东 · Temporal长任务与 HITL。Worker 不持 SoR 密钥。
西 · InnerLoop SPI默认 LangGraph。工具回调只能进 Hub。
知识 · Cube / 图 / WM口径、时态、三寿命。Cube 不签发任务。
水平 · A2AP0 用 task.transfer。对端仍进对方 Hub。
身份 · OIDCIdP 只提供人。岗位与承诺权在 Hub。
演化 · ChangeSetauto_apply=false。NocoBase 发布只走 submit。

集群集成原则

模块之间不进对方数据库。控制流、数据流、管理流分名。零件可换，一线名词不变。NocoBase 是 Platform Console 可视化壳，不是数据核。

  • WorkStudio 不直连任何零件
  • Lethe 不连责任图 / Graphiti / Cube
  • Graphiti mutation 不等于 cs 写
  • Temporal 不解释 Law Pack
  • NocoBase 主库不存 ag_node / episode / kpi.is

# AIOS WorkStudio · 赛道竞争焦点与创业领先路径

> 问题：这个赛道真正的竞争焦点是什么？核心矛盾是什么？创业如何超越对手、占领市场和用户心智？  
> 结论先行：**不要在「更好的 AI 办公工作台」上全面领先巨头；要在「可执行的商业世界模型」上品类领先，再用一条岗位闭环占领心智。**  
> 版本：T0.1 · 2026-08-22  
> 产品契约：`T0产品定义.md`  
> 行业事实：2026-08 对照 Codex harness、OpenClaw / Hermes / Claude Code、WorkBuddy / 千问办公 / TRAE Work。

---

## 0. 先把「全面领先」说清楚

腾讯 WorkBuddy（公开口径约 2000 万月活）、阿里千问办公（钉钉+通义+Qoder 整合）、字节 TRAE Work，已经在 **分发、积分、连接器、IM、专家市场** 上开战。创业公司用同一张功能清单去「全面领先」，12–18 个月内几乎必然失败。

可赢的「领先」只有三种，必须选，不能口头全要：

| 领先类型 | 含义 | T0 是否追求 |
|----------|------|-------------|
| 面积领先 | Skill 更多、专家更多、IM 更全、更快更便宜 | **否**。这是巨头的正面对抗面 |
| 品类领先 | 用户想起「把工作做成可交差、可追责、可进化」只想到你 | **是。心智目标** |
| 闭环领先 | 在一条高价值岗位流上，验收率与信任显著高于工作台竞品 | **是。市场切入** |

品类领先 + 闭环领先，才可能在 3–5 年后反过来吸收工作台用户。面积领先是结果，不是策略。

## 1. 赛道真正的竞争焦点

表面大家都在比：工作台、专家、Skill、连接器、IM 遥控、定时任务、云端托管。积木已经同构。再比下去是运营战。

真正的竞争焦点是下面这一句：

> **谁能把组织里正在发生的工作，编译成可执行、可追责、可进化的对象，并按任务价值分配智能。**

拆开是四个焦点，不是四个功能：

1. **工作对象 vs 对话框**  
   Codex 已经写明：应用拥有界面与记录，harness 只提供循环。办公巨头仍以对话为默认入口。谁先让「案件 / 候选人 / 单据 / 岗位流程」成为一级公民，谁就拥有组织场景。

2. **判断信用 vs 完成速度**  
   同一份周报：WorkBuddy 7 分钟交初稿，千问办公 41 分钟交研究过程。分水岭不是谁更快，是谁敢被拿去决策。用户两者都要，产品必须会分流，而不是站队。

3. **组织能力 vs 个人助手**  
   WorkBuddy 从白领习惯吃到 B 端预算；千问办公从企业级反向做。两者都还在「人 + Agent」层。企业真正买的是 **岗位能力可执行化**（授权、KPI、红线、审计），不是更会聊天的同事。

4. **知识协议 vs 人设商品**  
   Skill 标准（`SKILL.md` / agentskills.io）正在成为公共层。专家团是人设 SKU，好卖、难复利、难审计。谁把程序性知识做成可修订法则，谁拥有后台。

Harness 层（Codex / Claude Code / OpenClaw / Hermes）已经证明：**模型是租的，循环、压缩、审批、Skill 加载才是能力。** 办公产品若循环不达这个密度，前台再漂亮也是薄壳。

## 2. 核心矛盾（一条主矛盾 + 五条结构张力）

### 2.1 主矛盾

**获客要像助手，交付要像操作系统。**

助手逻辑：快、会聊、什么都能做、人设亲切、积分好懂。  
操作系统逻辑：有对象、有法则、有权限、有证据、有回滚、有进化。

巨头必须把前者做满，才能喂 Token、锁生态。他们不是不懂后者，是 **叙事和组织激励不允许把主路径从「AI 同事」改成「世界模型」**——改了就打掉自己已经占领的心智。

这就是创业窗口：用助手的入口习惯，交操作系统的结果；对外不说操作系统，对内必须是操作系统。

### 2.2 五条结构张力（决策前必须写明）

| 张力 | 巨头默认站位 | 我们的站位 | 若假装没有 |
|------|--------------|------------|------------|
| 速度 vs 判断 | 先完成再优化，或做重换信任 | **同一循环，按风险动态投放智能** | 要么轻飘要么又慢又贵 |
| 聊天框 vs 工作对象 | 对话是首页 | **对象是首页，对话是手段** | 永远停在 Copilot，进不了经营 |
| 个人记忆 vs 组织承诺 | 一套助手通吃 | **双轨不混权** | 一次越权毁掉企业单 |
| Token 量 vs Token 值 | 用量是经营指标 | **北极星是质量调整后的闭环成功** | 把自己做成模型公司的管道 |
| 人设 SKU vs 法则 Pack | 专家市场好卖 | **岗位法则先于人格** | 复制数字人失败史 |

主摩擦：用户看不见世界模型（认知摩擦），组织又要可审计承诺（治理/效率）。环位默认 In the loop。牺牲：不承诺「全自动替你做完」。

## 3. 对手地图：他们强在哪、死穴在哪

| 对手 | 心智占用 | 结构性强项 | 结构性死穴（我们可打） |
|------|----------|------------|------------------------|
| WorkBuddy | AI 同事 / 职场超能力 | 分发、腾讯生态、初稿速度、项目空间 | 判断链短；生态锁定；人设先于世界 |
| 千问办公 | 企业级 Agent / 过程可信 | 模型供给、钉钉、研究型链路 | 重、封闭、怕用户不会用而堆工作流 |
| TRAE Work | 信息覆盖 | 搜索半径 | 链接多 ≠ 密度；判断不是主路径 |
| Codex | 循环即平台 | Thread/Turn/Item、沙箱、嵌入对象 | 编码出身；办公场景与组织治理不是主场 |
| OpenClaw / Hermes | 常驻操作员 / 复利记忆 | 通道、自学、Skill 协议 | 单操作员；自学难审计；不是企业 OS |

巨头抄得最快的：工作台皮肤、专家卡片、连接器 logo墙。  
巨头抄得最慢的：五维对象、双轨权限、未接地不得进建议、改法则即改行为、跨生态中立。

不要在他们抄得快的面上加功能。要在他们抄得慢的面上做深，并让用户 **一周内感觉到差异**（德-用户-3：价值必须可感知）。

## 4. 心智占领：抢一个还没被登记的品类

已登记的心智：

- WorkBuddy：「你的 AI 同事」  
- 千问办公：「更会判断的企业 Agent」  
- Codex：「能嵌进产品的编码循环」

未登记、且与我们后台一致的品类：

> **交差操作系统** —— 让岗位把工作做成可交差、可追责、可进化。

对外一句话（用户语言，禁止先讲世界模型）：

**不是帮你写，是帮你把这件事做成一份过得了关的工作。**

过关 = 有对象、有证据、有边界、有下一步、能回改。  
这与「更快出稿」「更会长文」区隔，也与「41 分钟研究过程」区隔：我们不是默认做重，而是 **知道这件事过关要多深**。

禁止对外口号：更好的 WorkBuddy、更全的专家团、中国版 Codex、数字员工。  
对内口令：法则编译器；前台像工作台，后台是世界模型。

## 5. 创业路径：楔子 → 心智 → 平台（不可跳步）

### 第一阶段 · 楔子（0–6 个月）：一条价值流的闭环领先

选 **一个** 高判断、高频、可审计的岗位流做透。默认招聘短名单（仓库已有原型）；若商业上更近客户，可换成销售报价或工单升级，但同时只许一条。

验收（72 小时可证伪）：

- 岗位主体能指认：谁、对谁、对象、时间、反馈。  
- 未接地分数不进入建议。  
- 改一条法则，下次执行行为变了。  
- 产出被真人接受或驳回，驳回写回 ChangeSet。

这一阶段的用户不是「全体白领」，是 **该岗位的 Owner + 一线执行者**。赢他们，才有案例打心智。

### 第二阶段 · 心智（6–18 个月）：Copilot 入口 + 岗位中枢

员工侧给 Copilot（会用工作台的人能上手），但每次高价值任务都落到同一世界模型，而不是另一条聊天记录。  
对外传播只讲三个可感知差异：

1. 过关：证据和不确定点默认可见。  
2. 深浅：简单快走，复杂加深，高风险停手。  
3. 进化：你改一次，全岗位下次生效。

销售打法：用闭环案例打部门预算，不先打集团「AI 中台」大单。中台叙事是巨头的主场。

### 第三阶段 · 平台（18–36 个月）：能力中枢被其他场景复用

此时才打开第二条价值流。复用的是统一语言和 `cs.*`，不是复制一套专家。  
Harness 继续外购/对齐（Codex app-server 或 Pi 级循环 + Skill 协议）。自建循环是分心，不是壁垒。

壁垒顺序：

1. 岗位法则 Pack（领域 know-how 的可执行化）  
2. 审计与双轨（企业敢上生产）  
3. 统一语言（切换场景的迁移成本）  
4. 最后才是分发

## 6. 如何「超越」：不对称打法（八条）

1. **循环采购，法则自研。** 用 Codex/Pi 级 harness 补 Skill 加载、压缩、沙箱；把工程火力留给世界模型与门禁。对手在堆专家 SKU，我们在堆可修订法则。  
2. **动态智能投放做成产品身份。** 不要在「7 分钟」和「41 分钟」里选边。产品必须能解释：这件事为什么走快路径 / 为什么核验。这是元认知，也是 Token 价值观。  
3. **对象首页，对话降级为手段。** 学 Codex Relay：点在记录上的动作，而不是空白 prompt。办公巨头短期内不敢放弃对话框首页。  
4. **双轨作为企业信任引擎。** 个人加速、经营升级、证据随意图走。这是采购部门能听懂的「不会乱来」。  
5. **跨生态中立。** 同时服务企微 / 钉钉 / 飞书而不做它们的附属。巨头做不到真中立。入口可以借 IM，主权不能借。  
6. **诚实当功能。** 「单一信源 / 未授权 / 不知道」是卖点，不是缺陷。判断信用一旦建立，切换成本高于再装一个工作台。  
7. **组合，不单干。** 书桌循环（Claude Code/Codex 纪律）+ 常驻入口（OpenClaw 级通道）+ 可审计写回（Hermes 的复利减去静默漂）。OS 编排多家循环，不押一家替换全部。  
8. **价值可感知优先于架构正确。** 招聘 OS 已证明：能力在脚本里、入口不对，价值为零。T0 必须有岗位主体一周内能演示的过关时刻。

## 7. 红队：这条路最容易怎么死

| 攻击 | 若成立则策略失效 | 对策 |
|------|------------------|------|
| 巨头加「研究模式」开关 | 动态深浅被抄成套餐档位 | 深浅必须挂对象与法则，而不是套餐名 |
| 客户听不懂世界模型 | 品类无法占领心智 | 对外只说交差/过关/下次生效 |
| 先做平台再找场景 | 18 个月无闭环 | 锁死一条价值流 |
| Copilot 很好用，岗位流没人开 | 退回 WorkBuddy 追随者 | 指挥席与员工必须同一模型，分权不分叉 |
| 自学写回法则造成漂移 | 企业不敢用 | 写回必须进 ChangeSet，禁止静默 |
| 想全面领先功能面 | 烧在面积战 | 每月用本文件 §0 表格审查需求 |

单点破坏测试：若「可执行世界模型」做不出来，只剩工作台，产品应停，而不是改名继续做 AI 同事。

## 8. 72 小时可执行动作

1. 冻结品类句：对外「过关的工作」，对内「法则编译器」。任何稿件不得出现「对标 WorkBuddy」。  
2. 冻结 T0 价值流：一条，写进 `T0产品定义.md` §6，签字。  
3. 列一张张力表：当前要做的功能降低的是认知摩擦、执行摩擦还是知识摩擦；降不了的不做。  
4. 对齐 Skill 协议与循环采购决策（Pi / Codex core），停止自研不会加载 Skill 的 Agent 层。  
5. 定义北极星口径：质量调整后的闭环成功，并规定未接地陈述的否决条件。

---

## 9. 一句话结算

这个赛道的竞争焦点不是办公 Agent 谁更像同事，而是 **谁把工作编译成组织可执行的对象**。  
核心矛盾是 **助手的获客方式 vs 操作系统的交付方式**。  
创业要全面领先，只能领先品类和闭环，不能领先巨头的面积。  
占领心智靠一句用户语言：**帮你把这件事做成过得了关的工作**；占领市场靠一条岗位价值流先赢，再让能力中枢被第二、第三条流复用。
